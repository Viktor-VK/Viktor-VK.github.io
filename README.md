# Viktor-VK.github.io

Личный сайт-портфолио аналитика данных: https://viktor-vk.github.io/

Сделан на [Astro](https://astro.build), деплоится в GitHub Pages через GitHub Actions при push в `main`.

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # сборка в dist/
```

- `src/data/profile.ts` — имя, описание, контакты
- `src/data/projects.ts` — карточки проектов на главной
- `src/pages/projects/` — страницы исследований
